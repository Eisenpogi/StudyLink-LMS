LOGIN SYSTEM

Three separate portals:

admin/index.php
faculty/index.php
student/index.php

Only ONE users table.

users columns:

id
fullname
username
password
role
status
created_at

Roles:

admin
faculty
student

Each login form sends:

portal=admin
portal=faculty
portal=student

login_process.php validates role == portal

Redirects:

admin -> admin/dashboard.php
faculty -> faculty/dashboard.php
student -> student/dashboard.php
